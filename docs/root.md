# ROOT

Ver las versiones de ROOT instaladas:

```bash
list_root
```

Cargar una versión, o la última disponible si no indicás ninguna:

```bash
load_root <name>
load_root
```

!!! note "ATLAS"
    También se puede usar `lsetup root`, `lsetup views`, etc. después de `setupATLAS`, como en lxplus. Ver [ATLAS](atlas.md).
